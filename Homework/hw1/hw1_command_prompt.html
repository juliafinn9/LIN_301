HW 1 — The Command Prompt

LIN 301: Computation for Linguists

Author

Dr. Andrew M. Byrd

Overview

During class in week 2 you learned how to navigate, create, move, and search files entirely from the Terminal — no mouse required. This assignment asks you to do the same set of tasks on a new text (not one we used in class), so you’re practicing the skills rather than replaying what you already typed.

By the end, you should be able to:

  • Navigate a file system and create/rename/remove files and folders from the command line.
  • Write and run a short shell script that automates a repeatable setup task.
  • Use wc, grep, and piping (|) to count and search inside a text file.
  • Write basic regular expressions (grep -E) to find patterns in text.

You will create one Quarto document named hw1_command_prompt_lastname_firstname.qmd, living inside a folder called hw1 in your homework/ folder — you won’t submit this file itself, just a URL pointing to it (see Submission below for exactly how that works). For every numbered task below, record in your document: (a) the exact command(s) you typed, in a fenced bash code block; (b) whenever a task says “record,” “confirm,” or otherwise asks you to report a result, the actual terminal output, pasted as a second code block right below the command that produced it; and (c) the answer to any question that’s asked. You’re documenting what you did in the Terminal — none of these code blocks need to be “run” by Quarto itself.

Part 1 — Navigating & Managing Files

Do all of the following inside the integrated Terminal in VSCode. cd into your LIN_301/homework folder, then create a new folder called hw1 and cd into it — this is where everything for this assignment lives, both your working files and your .qmd write-up. Copy the assignment file from your 301_2026 folder into this new folder, renaming it as you go — this becomes the document you’ll actually work in:

cp ~/301_2026/homework/hw1_command_prompt.qmd ./hw1_command_prompt_lastname_firstname.qmd

  1. Download The Adventures of Sherlock Holmes from Project Gutenberg using curl, naming the file holmes.txt: https://www.gutenberg.org/cache/epub/1661/pg1661.txt

  2. Confirm the file downloaded and check its size using ls -l.

  3. Create three nested folders: drafts > working > final (i.e., working sits inside drafts, and final sits inside working).

  4. Use touch to create an empty file called log.txt.

  5. Move log.txt into the final folder.

  6. You’ve decided drafts is a bad name for the top folder — rename it to notes (remember: mv is also how you rename in bash).

  7. Create one more throwaway folder called scratch, then remove it using rm -r.

  8. Write a script. Create a file called setup.sh that, when run, does the following in one shot:

    • creates a new folder called backup_check
    • downloads holmes.txt again into that folder (same curl command as step 1, adjusted for the new destination)
    • prints a message to the screen confirming the download (echo)

    Run your script with source setup.sh and confirm it worked with ls.

Question: What’s the difference between rmdir and rm -r? Why did you need rm -r in step 7 and not rmdir?

Part 2 — Counting & Searching

  1. Run wc, wc -l, and wc -w on holmes.txt. Record all three outputs.
  2. Use grep to find every line containing the name “Watson”. Then pipe that into wc -l to get a single count of how many lines mention him.
  3. Do the same for “Holmes”. Which name appears on more lines?

Part 3 — Regex Challenges

Using grep -E on holmes.txt, find each of the following. For each one, write the command you used and the answer/result.

  1. Every instance where a word begins with “Holmes” or “Watson.”
  2. All five-letter words in the file.
  3. All lines that end in a question mark (remember ? is a special character in regex — you’ll need to escape it with \).
  4. All instances of a letter repeated twice in a row (like “ee” in “sleep” or “ss” in “glass”), using a backreference.
  5. The total number of times “he” or “He” or “she” or “She” appears as its own word (not buried inside a longer word like “the” or “shelf”).

Part 4 — Reflection

At the bottom of your document, write a short (3–5 sentence) reflection:

  • What was the easiest part of this assignment? What was the hardest?
  • Now that you’ve used grep and regex on an English text, can you think of a linguistic question (phonological, morphological, syntactic) you could investigate this way on a text or corpus?
