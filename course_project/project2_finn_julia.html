I used AI to help brainstorm how to store the poems names and their corresponding text. I also used AI auto-complete in VS code when copying the same code and changing the variable names.

  1. The Raw Data My raw data is composed of two text files that each contain three poems by Tyutchev. I used ChatGPT to create the text files. I did not change my dataset from Component 1. https://github.com/juliafinn9/LIN_301/blob/main/course_project/project1_finn_julia.qmd

  2. Cleaning Steps

When I cleaned my data, I first split my text from the titles of the poems. Then I split the text and removed white space as well as non-word characters. After that, I lowercased my data. Finally, I removed all empty strings. I lowercased the text, which I believe will make the data a lot easier to analyze. However, it cost me being able to see what word each line starts with. However, if this becomes a problem later on, I can adjust my code.

  1. The Clean Table I created two tables for each text file. In my DataFrame, I created a row that gives the number of order of each word in the text. The column I made gives each word in the text. There are 420 rows in each table (420 words in each text file, excluding title names)

  2. Still Messy

When I created these text files from ChatGPT, I didn’t notice that the diacritics above a specific letter wasn’t included. I noticed this as I was looking through my data during this project. Before Component 3, I need to go and look back at the original source that ChatGPT got the poems from and see if the diacritics were included. If they were, I will need to figure out how to address that problem. There is nothing in my data, that I wish I had kept.
